这是可运行 MVP，不是静态原型。界面框架（三栏工作台、手机外壳、P1–P7、7 屏总览、底部 tab、演示控制、右侧对照）逐字沿用你已认可的 demo，只把数据层换成真实实现。

MVP 新增能力：① Web Bluetooth 真连 GL-BLE# 卡尺，解析 DAT0/DAT1、拆包粘包、inch→mm、完整帧回 DAT0:OK、MEAS/CLR/MOD 指令；② 10 通道独立订阅 / 去抖 / 落库，跨通道不去重；③ IndexedDB 本地库，收到即落库、刷新不丢；④ 真实 CSV 导入导出（BOM / 中文别名 / CHANNEL 列）与图表 PNG 导出；⑤ 诊断日志、屏幕常亮、断连保护。

无卡尺时自动进入演示模式，注入的原始帧走同一条解析 → 去抖 → 落库 → 渲染链路；左下「演示控制」是状态注入器，不属于业务功能按钮。

README ④ 页面文字原型 · 合并页
MVP 已在浏览器里跑通协议解析、本地库与导入导出；它不是 Android APK。已确认的技术路线 C（原生 Kotlin + Room + blessed-android + Vico）仍是正式 App 落点，本机无 JDK / Android SDK，无法编译验证，故本版用于先把功能链路与界面跑通。
正式 APK 与 M0 实机验证（7 路协议栈上限、10 路机型实测、release 签名）仍待有卡尺与真机后推进；技术基线以 V1开发基线.md 为准。
v1.0 只加「真实链路 + 10 通道」，界面框架与既有功能保持不变。
